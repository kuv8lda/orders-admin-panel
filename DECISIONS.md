# DECISIONS

Отклонения от ТЗ и принятые решения, по одной строке: что, почему.

- Тесты прогнаны временным раннером (pytest в среде не установить, сети нет): 113 из 113. Настоящий `pytest -q` нужно запустить один раз у себя.
- `ruff` не запускался (нет сети). В `pyproject.toml` оставлен набор правил по умолчанию; неиспользуемые импорты найдены и убраны вручную. `ruff format` в CI не включён, пока код не прогнан форматтером.
- Docker, docker compose и gunicorn не запускались (их нет в среде). Dockerfile и compose написаны, но не проверены; приложение целиком проверено через `python app.py` и Chrome.
- Chart.js 4.5.1 (из npm-пакета, вместо 4.4.1 из ТЗ) лежит в `js/vendor`. Из Font Awesome 7.3.1 (пришёл «desktop»-архив без CSS и woff2) взяты SVG 26 используемых иконок, `scripts/build_icons.py` собирает из них `css/vendor/fa-icons.css` на mask-image: иконки без шрифтов и CDN, разметка не изменилась. CSP разрешает только свой origin. Добавлен `img/favicon.svg`, чтобы не было 404 на favicon.
- Интерфейс панели RU/EN сделан (`js/i18n.js`, ключи сверяет `tests/test_i18n.py`). Сообщения API остаются английскими (контракт, тесты), интерфейс переводит их по таблице. Статусы в RU: «Ожидает оплаты», «Оплачен», «Передан в доставку», «Выполнен», «Отменён» (те же формулировки пойдут в бота).
- Попутно исправлено: параметр `next` на странице входа допускал открытый редирект (`safeNextPath`); демо-заказы и события создавались «из будущего»; пустая третья колонка сетки; тень закрытой карточки заказа на краю экрана; переполнение шапки и фильтров на телефоне.
- Добавлена переменная `COOKIE_SECURE`: без неё в Docker на `http://localhost` нельзя войти (cookie с флагом Secure не сохраняется).
- `/healthz` лежит вне `/api/`, поэтому охранник `/api/*` его не затрагивает и в allowlist не добавлялся. Тест проверяет, что он открыт и не ставит cookie.
- Образ запускает один процесс gunicorn с потоками: ограничение попыток входа хранится в памяти процесса.
- `TRUST_PROXY=1` реализован через `ProxyFix(x_for=1)` (доверяем одному прокси, берём последний адрес из `X-Forwarded-For`).
- `Strict-Transport-Security` без `includeSubDomains`, чтобы не задеть чужие поддомены; ставится всегда, кроме режима отладки.
- Ротация сессии при входе: вход уже делает `session.clear()` и выдаёт новый CSRF-токен; сессии клиентские (подписанные cookie), серверного идентификатора нет. Отдельной ротации не добавлял.
- Старый `instance/app.db` в истории git содержит только демо-данные (60 заказов, 150 событий), чистка истории не обязательна. Историю не трогал.
